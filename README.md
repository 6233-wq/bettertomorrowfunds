# BetterTomorrowFunds Website

A responsive, GitHub Pages-ready website inspired by the provided BetterTomorrowFunds screenshots.

## Files

- `index.html` — Home page
- `about.html` — About Us page
- `team.html` — Team page
- `style.css` — all styling
- `script.js` — mobile navigation + footer year
- `assets/` — BetterTomorrowFunds logo and the three provided informational images

## GitHub Pages

1. Create a GitHub repository.
2. Upload every file and the `assets` folder while keeping the same folder structure.
3. In GitHub, open **Settings → Pages**.
4. Under the deployment/source section, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder.
6. Save.
7. GitHub will publish `index.html` as the home page.

No Cloudflare Workers or Wrangler configuration is required for this version.

## Custom domain

If you connect `bettertomorrowfunds.org` to GitHub Pages, use GitHub's Pages custom-domain settings and follow the DNS records GitHub provides for your repository. Do not add a Worker.
